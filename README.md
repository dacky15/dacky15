### 🧭 How I work as a PM

1. **Start from the last time it happened.** Interview users about real events, not hypotheticals ([my interview guide](https://github.com/dacky15/courtlegacy-case-study/blob/main/research/interview-guide.md)).
2. **Write it down.** A PRD with goals, non-goals, metrics and the riskiest assumptions ([example](https://github.com/dacky15/courtlegacy-case-study/blob/main/docs/PRD.md)).
3. **For AI features, define "good" before building.** An eval set, a safety invariant, and a baseline that proves the eval isn't trivial to pass.
4. **Ship, measure, iterate.** A north-star metric plus guardrails, and every production failure becomes a new eval case.
